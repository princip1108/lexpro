## 单个任务的完成标准

1. 实现前明确写出行为要求和不包含的范围。
2. 代码遵循模块边界和安全规则。
3. 相关自动化测试通过。
4. 受影响的应用能够成功构建。
5. 真实接口或界面可以人工验证。
6. 中英文文档和本计划同步更新。
7. Git 差异中只有本任务的预期修改。
