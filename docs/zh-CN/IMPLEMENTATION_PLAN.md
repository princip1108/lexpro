## 当前基线

- [x] Vue 3 前端原型和 Mock 数据。
- [x] PostgreSQL V1/V2/V3 数据库设计，最终 32 张表。
- [x] Java 21 + Spring Boot 3.5.16 后端工程。
- [x] PostgreSQL 连接和数据库健康检查接口。
- [x] MyBatis-Plus 集成。
- [x] 用户只读列表，默认不查询和返回密码。
- [x] Controller 测试和应用上下文测试。

## 单个任务的完成标准

1. 实现前明确写出行为要求和不包含的范围。
2. 代码遵循模块边界和安全规则。
3. 相关自动化测试通过。
4. 受影响的应用能够成功构建。
5. 真实接口或界面可以人工验证。
6. 中英文文档和本计划同步更新。
7. Git 差异中只有本任务的预期修改。
